# Peter Kayode — portfolio

A responsive, static portfolio for Odunmorayo Peter Kayode. It uses plain HTML,
CSS, and JavaScript and has no package or build dependencies.

## Preview

Open `index.html` in a browser, or serve this folder from any static web host,
including GitHub Pages or Vercel.
For local development, a simple option is:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing

- The TIE project links to its live website at `https://tieprocurements.com`.
- Review the email, phone, LinkedIn, education, and role details for accuracy.
- The portrait in `assets/peter-kayode.jpe` is the image supplied for this site.

Project links point to the public repositories where available. TIE's repository
is private, so the portfolio links to the product address rather than its source.

## Vercel deployment

Import the `peter-kayode-portfolio` repository into Vercel. This is a static
site with no build step: leave the framework preset as **Other**, leave the
build command and output directory blank, and deploy the repository root.
